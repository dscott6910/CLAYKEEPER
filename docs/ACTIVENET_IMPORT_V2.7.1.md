# ClayKeeper v2.7.1 - User-Selected ActiveNet Files

ClayKeeper keeps the permanent ActiveNet importer but does not include or preload any ActiveNet spreadsheet. Administrators upload their own current `.xlsx`, `.xls`, or `.csv` export each time they perform an import.

## Workflow

1. Open **Seasons & Historical Import**.
2. Choose the ClayKeeper season.
3. Enter the registration event name.
4. Choose the registration date.
5. Select the ActiveNet export from the local computer.
6. Review validation, preview, warnings, and errors.
7. Start the import and monitor progress.

The original spreadsheet is not bundled with the application. Import History retains only the filename, status, summary information, and linked database records.
