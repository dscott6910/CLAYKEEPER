# ClayKeeper v2.5.0 - Awards Readiness and Print Polish

- Added an Event Readiness panel to the CYSSA Awards page.
- Checks selected shoot, available results, scoring completion, unresolved ties, and publication status.
- Displays ACTION REQUIRED, READY TO PUBLISH, or READY TO ANNOUNCE.
- Added unresolved tie totals across individual, squad, state-team, and series-team reports.
- Added print styling so Print / Save as PDF outputs the award report without application controls.
- No database migration is required.
