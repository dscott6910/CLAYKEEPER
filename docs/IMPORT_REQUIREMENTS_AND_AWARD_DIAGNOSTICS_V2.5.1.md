# ClayKeeper v2.5.1

## Required import setup

Trap Series and US Open imports now require a season, event/series name, and date before a workbook can be selected or imported. Required fields are visibly marked and the workbook picker remains disabled until setup is complete.

## Award readiness diagnostics

The Awards & Results readiness panel now lists each issue instead of only showing a total. Diagnostics identify incomplete participants, individual ties, squad ties, state-team ties, series standings ties, and unpublished awards. Report-related issues link directly to the appropriate report tab.

No database migration is required.
