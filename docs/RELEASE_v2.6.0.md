# ClayKeeper v2.6.0 — Branding & Organization Settings

## Included

- Final ClayKeeper TMK logo with no apostrophe-S.
- Branded sidebar, login screen, dashboard, awards reports, browser title, favicon, and installable-app icons.
- Functional organization settings for organization name, report subtitle, report footer, and support email.
- Print-ready ClayKeeper logo header and configurable footer on Awards & Results reports.
- Sidebar navigation section headings and corrected application version display.

## Database

No Supabase SQL migration is required.

## Start

From the frontend folder:

```bash
npm install
npm run dev
```

Normal startup after dependencies are installed:

```bash
npm run dev
```
