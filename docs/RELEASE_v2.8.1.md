# ClayKeeper v2.8.1 — ActiveNet Import Stability

- Fixed the reviewed-participant import action and added visible database error details.
- Added import progress and a clear explanation when possible matches still require review.
- Added Remove File, Choose Different File, and Import Another File actions.
- Added ActiveNet Import History with deletion of an import and its linked ActiveNet registration records.
- Deleting an ActiveNet import does not delete Participant Directory records.
- ActiveNet remains separate from shoots, scores, squads, and competition events.
