CLAYKEEPER - Complete ActiveNet Participant Import

From inside the frontend folder:

npm install
npm run dev

Normal startup after dependencies are installed:

npm run dev

Apply the Supabase migrations before using the updated ActiveNet import. The
20261105010000_activenet_registration_report_fields.sql migration preserves
the complete source row and adds participant/update counts to import history.

Preserve your existing frontend/.env file. No ActiveNet spreadsheet is included in this project package; select your own export from the ActiveNet import screen.
